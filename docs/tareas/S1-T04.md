## Objetivo

Dejar un proyecto Android que compile, instale y muestre una pantalla vacía,
con todas las dependencias del stack ya configuradas. A partir de aquí todos
los demás trabajan.

## Qué hacer

Proyecto con `applicationId` `mx.donchambitas.app`, `minSdk` 26, `targetSdk` 35.

Dependencias en el catálogo de versiones (`libs.versions.toml`), nunca sueltas
en el `build.gradle.kts`: Compose BOM y Material 3, Hilt, Navigation Compose,
**`supabase-kt`** (módulos `postgrest`, `auth`, `storage`, `realtime` y
`functions`) con kotlinx.serialization, DataStore, Coil, Coroutines, y para
pruebas JUnit, MockK y Compose UI Test.

**Sin Retrofit ni OkHttp**: salieron del stack con DEC-17. `supabase-kt` trae su
propio cliente HTTP.

Hilt necesita el plugin de **KSP** declarado aparte. Ojo con esto: el proyecto
usa AGP 9 con soporte de Kotlin integrado, así que hoy compila sin declarar
ningún plugin de Kotlin, y eso deja de bastar en cuanto entra Hilt.

Las credenciales de Supabase (URL del proyecto y `anon key`) **no van
escritas en el código**. Van en `local.properties`, que está en `.gitignore`, y
llegan a `BuildConfig` desde ahí. La `service_role` key no entra al proyecto por
ningún motivo.

`DonChambitasApp` anotada con `@HiltAndroidApp`. `MainActivity` con
`@AndroidEntryPoint` y un `setContent` que muestre un texto de marcador.

## Criterios de aceptación

- [ ] `./gradlew assembleDebug` termina sin errores ni advertencias de
      dependencias
- [ ] La aplicación instala y abre en un dispositivo o emulador
- [ ] Todas las versiones viven en `gradle/libs.versions.toml`
- [ ] Hilt está activo: la aplicación arranca sin error de inicialización
- [ ] `supabase-kt` está en el catálogo y el proyecto compila con él
- [ ] La URL y la `anon key` se leen de `local.properties`, no del código
- [ ] `grep -rn "service_role" .` no devuelve nada
- [ ] `./gradlew testDebugUnitTest` corre, aunque no haya pruebas todavía

## Cómo probarlo

```bash
./gradlew clean assembleDebug
./gradlew installDebug
```

Abre la aplicación. Debe mostrar la pantalla de marcador sin cerrarse.

## Fuera de alcance

Nada de tema, colores, navegación ni pantallas reales. Solo el andamio.

**No se crea el cliente de Supabase ni se llama a nada.** Solo se agrega la
dependencia y se deja lista la lectura de credenciales. El cliente se construye
en S2-T07, que es la primera tarea que de verdad lo usa.
