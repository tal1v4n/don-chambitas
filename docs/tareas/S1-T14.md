## Qué hacer

Dibuja las siete en cualquier herramienta, a 360 por 800 dp. Usa la paleta
Taller y los componentes de S1-T10: si un wireframe pide algo que no existe como
componente, o lo cambias, o lo reportas.

Marca en cada uno qué componente se usa en cada zona, con el nombre exacto del
componente.

Dibuja también los estados vacío y error de P-05 y P-10. Son los que más se van
a ver en las primeras pruebas.

`WIREFRAMES.md` es el índice: una tabla con ID de pantalla, imagen y notas de
comportamiento (qué pasa al tocar cada cosa).

## Criterios de aceptación

- [ ] Existen las siete imágenes más los estados vacío y error de P-05 y P-10
- [ ] Cada zona está anotada con el nombre exacto del componente
- [ ] Ningún wireframe usa un componente que no exista en `DISENO.md`
- [ ] Ningún wireframe usa un color fuera de la paleta Taller
- [ ] `WIREFRAMES.md` describe el comportamiento de cada elemento tocable

## Cómo probarlo

Cruza cada wireframe contra la tabla de componentes de `DISENO.md`. Cada
elemento debe corresponder a un componente existente.

## Fuera de alcance

Solo estas siete pantallas. Las otras doce se dibujan en su sprint.
